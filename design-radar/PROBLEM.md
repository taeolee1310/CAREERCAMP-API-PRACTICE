# 문제 정의

## 누구의 문제인가
디자이너 인턴인 나. 같은 처지의 주니어 디자이너에게도 해당한다.

## 어떤 문제인가
| 막히는 지점 | 실제로 벌어지는 일 |
| --- | --- |
| 아이디어가 흩어진다 | 떠오른 생각을 메모해도 나중에 못 찾고 이어가지 못한다 |
| 레퍼런스·트렌드 수집 | 사례와 동향을 모으고 정리하는 데 시간이 든다 |
| 무엇을 만들지 모른다 | 서비스·포트폴리오 주제를 못 정하고 탐색만 길어진다 |
| 만든 뒤 일관성 부족 | 바이브코딩 결과물의 스타일과 구조가 매번 달라진다 |

네 가지는 따로 떨어진 문제가 아니라 한 고리다. 입력(아이디어)이 흩어지고, 재료(트렌드)를 따로 모으다 보니, 탐색이 길어지고, 만들어도 결과가 들쭉날쭉하다.

## 해결 방향
말로 던진 아이디어와 매일 받는 디자인 뉴스를 한곳에 쌓아, 만들 거리를 발견하게 돕는 개인 도구. 일관성은 규칙·스킬 md로 잡는다.

## 정해진 것
- 입력: PC 브라우저 음성(Web Speech API, 무료)
- 정리: 무료 LLM API가 키워드로 정리 → 프로젝트 폴더에 md 저장. 배포판은 md 다운로드
- 뉴스 분야: UI/UX 트렌드, AI×디자인, 브랜딩·그래픽, 국내 디자인 소식
- 구조: 정적 프론트 + Python `api/` (Vercel 배포), 애니메이션은 GSAP
- 무드: 대시보드 + 음성 메모 도구가 섞인 느낌. 미니멀하고 차분한 색(색은 나중에 직접 검토)
- 뉴스 출처: UI/UX(Nielsen Norman Group, Smashing Magazine, UX Collective) + 국내(요즘IT, 토스 테크, 우아한형제들, 카카오 기술블로그, 디자인 키워드 필터)
- LLM: Google AI Studio 무료 키, gemini-3.5-flash-lite
