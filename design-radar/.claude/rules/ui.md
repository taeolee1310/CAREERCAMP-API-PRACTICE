## 화면 규칙
무드는 "대시보드 + 음성 메모 도구". 조용한 바탕 위에서 마이크와 키워드가 살아 움직이는 화면이다.

### 토큰과 구조
- 색·간격·글자 크기·곡선·시간은 `public/css/tokens.css`의 CSS 변수로만 쓴다. JS에서 시간이 필요하면 `getComputedStyle`로 토큰을 읽는다. 다른 CSS·JS 파일에 색상 값(`#…`, `rgb()`, `hsl()`)을 직접 쓰지 않는다. (왜: 일관성을 한 곳에서 잡으려고)
- 다크/라이트: 다크 값은 `:root[data-theme=dark]`와 `@media (prefers-color-scheme:dark){ :root:not([data-theme=light]) }` 두 곳에 같은 값을 넣는다. 선택은 `localStorage`의 `theme`에 저장하고, 없으면 기기 설정을 따른다.
- 외부 스크립트는 GSAP 하나만 쓰고 버전을 고정한 CDN 주소(`gsap/3.12.5`)를 `public/index.html` 한 곳에만 둔다. 다른 애니메이션 라이브러리를 추가하지 않는다. GSAP이 안 불러와져도 내용은 보여야 한다(애니메이션만 빠짐). (왜: 움직임이 매번 달라지지 않게)
- 피드에서 온 글자는 `textContent`로만 넣는다. `innerHTML`에 외부 데이터를 넣지 않는다.
- 한 화면 안에서 카드·버튼·입력창은 같은 모서리 반경·그림자 토큰을 쓴다.

### 움직임
- `transform`과 `opacity`만 애니메이션한다. `transition: all`은 쓰지 않는다.
- 시간과 곡선은 `--dur-*`, `--ease-*` 토큰만 쓴다. GSAP은 CSS 곡선을 못 읽으므로 `--gsap-ease-*`, `--stagger` 토큰을 `cssVar()`·`cssSec()`로 읽는다(플러그인 추가 금지). 등장은 요소 하나의 duration이 500ms 이내, 눌림은 `scale(.96)` 120ms.
- 목록 등장은 stagger를 쓰되 전체 길이(delay + stagger 합 + 마지막 칸 duration)를 600ms 안으로 한다.
- 화면마다 "시그니처 순간"을 하나만 둔다. 지금은 정리 결과의 키워드 등장(`--gsap-ease-pop`)이다. 소리 크기 링과 정리 중 맥동은 상태를 알려 주는 피드백이라 시그니처가 아니고, 뉴스 목록 등장은 조용하게 둔다. (왜: 전부 움직이면 아무것도 안 보임)
- `prefers-reduced-motion`이면 이동·크기 변화를 빼고 투명도만 남긴다. 소리 크기에 반응하는 모션도 같다.
- 블러는 `blur(14px)` 이하. 배경 효과는 `position:fixed` 레이어 하나에 둔다.

### 상태 화면
- API에서 불러오는 영역(뉴스 목록, 모아 둔 아이디어)마다 **로딩**, **비어 있음**, **실패** 세 상태를 만들고, 실패에는 다시 불러오기 버튼을 둔다. 배포판처럼 기능이 없는 경우는 실패와 다른 안내로 구분한다. 한 카드가 실패해도 다른 카드는 보인다.
- 마이크는 `대기 → 듣는 중 → 정리 중 → 저장됨 / 실패` 다섯 상태를 문구만이 아니라 모양·색으로도 구분한다. 음성 인식 오류(`not-allowed`, `audio-capture`, `no-speech`, `network` 등)는 모두 실패 상태로 보여 주고, 직접 멈춘 `aborted`만 조용히 넘긴다. 브라우저가 음성 인식을 지원하지 않으면 글로 입력하는 칸을 대신 보여 준다.

### 문구
- 해요체로 통일하고 한 문장에 정보 하나만 담는다.
- 실패 문구는 "무슨 일이 생겼는지 → 사용자가 할 일" 순서. 영어 오류 문구나 HTTP 번호를 그대로 보여 주지 않는다.
- 시간은 한국 시간(KST)으로 표시한다.

### 접근성
- 터치 대상은 44px 이상(문장 속 인라인 링크는 WCAG처럼 예외), 글자와 배경 대비는 4.5:1 이상. 대비를 깎는 `opacity`를 글자에 쓰지 않는다. 마이크 버튼에는 `aria-label`과 상태를 읽어 주는 `aria-live` 영역을 둔다.
- 키보드만으로 마이크 켜기·끄기, 탭 이동이 된다.
