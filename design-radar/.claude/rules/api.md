## API·서버 규칙
- 서버 코드는 `api/*.py`(Vercel Python 함수)에만 둔다. 외부 패키지 없이 표준 라이브러리(`urllib`, `json`, `xml.etree`)를 먼저 쓰고, 꼭 필요하면 먼저 묻는다. (왜: 배포 설정을 단순하게)
- 키는 환경변수(`os.environ`)로만 읽는다. 화면 코드, 로그, 응답, 샘플 파일, md 기록에 키를 넣지 않는다. 키가 든 주소는 오류 로그에도 남기지 않는다. 양식은 `.env.example`에 이름만 적는다. (왜: HTML은 누구나 볼 수 있음)
- 외부 호출은 `api/`가 대신 한다. 화면은 우리 `/api/...`만 부른다. 외부 주소는 각 파일 맨 위 상수 한 곳에 모으고 `# 🔌` 주석을 단다. 화면 쪽은 `const API = { ... }` 한 곳에 모으고 `// 🔌` 주석을 단다.
- 모든 응답은 `{ "ok": true, "data": ..., "asOf": "ISO 시각" }` 또는 `{ "ok": false, "error": "한국어 문구" }` 한 모양으로 통일한다.
- 같은 호출은 캐시한다(뉴스 30분 이상). 무료 한도를 넘지 않게 호출 횟수를 제한하고, 한도가 얼마인지 코드 주석에 적는다.
- 받는 입력은 길이와 문자 종류를 검사한다. 음성 원문은 최대 길이를 두고 넘으면 자른다.
- 업스트림 오류는 한국어 문구만 화면에 보낸다. 한 출처가 실패해도 다른 출처 결과는 돌려준다.
- 화면에 **데이터 출처**와 **기준 시각**을 적는다. 하루 한 번 갱신되는 데이터를 "실시간"이라고 쓰지 않는다. 뉴스 기사는 제목·출처·링크만 보여 주고 본문은 복사하지 않는다. (왜: 저작권)
- 새 무료 API를 쓰기 전에 이용 약관과 호출 한도를 확인해서 `api/README.md`에 한 줄 적는다.
